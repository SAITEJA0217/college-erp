# MRUH ERP - Placement Cell Manual

## Overview
The Placement Dashboard is a dedicated interface for managing corporate relations, campus recruitment drives, and tracking student career outcomes.

## 1. Campus Drives
- **Drive Management**: Create and schedule upcoming campus recruitment drives. Specify the visiting company, date, eligibility criteria (e.g., minimum CGPA, branches allowed), and package details.
- **Drive Tracking**: Monitor how many students have registered for each active drive.

## 2. Student Applications
- **Application Portal**: Review student registrations for specific drives.
- **Shortlisting**: Mark students as shortlisted for interviews or selected/hired once the process concludes.

## 3. Communication
- **Placement Announcements**: Broadcast targeted alerts specifically about pre-placement talks, aptitude test schedules, and interview lists.
- **Notifications**: Keep track of system alerts related to corporate schedules.

## 4. Reports
- Generate holistic reports on the percentage of students placed per department, average packages, and top recruiters to present to university leadership.
