# MRUH ERP - Faculty User Manual

## Overview
The Faculty Dashboard provides tools to manage daily academic duties, track student progress, and communicate.

## 1. Daily Operations

### 1.1 My Classes & Timetable
- **Timetable**: View your weekly schedule showing which section and subject you are teaching at what time.
- **My Classes**: Provides a quick overview of all the sections assigned to you.

### 1.2 Attendance
- Navigate to `Attendance`.
- Select your assigned section and subject for the day.
- Mark students as Present or Absent. The system tracks this instantly to provide real-time attendance percentage to students.

## 2. Learning Management

### 2.1 Study Materials
- Navigate to `Study Materials` to upload PDFs, presentations, or documents.
- Materials are tied to specific subjects and are instantly available for download by enrolled students.

### 2.2 Assignments & Quizzes
- **Assignments**: Create assignments with due dates and optional attachment instructions. You can view all student submissions and grade them directly.
- **Quizzes**: Build interactive multiple-choice quizzes. Set a time limit and passing score. The system automatically evaluates student attempts.

## 3. Examination & Grading

### 3.1 Internal Marks
- Use the `Internal Marks` module to upload continuous assessment scores.
- You can enter marks manually or upload a formatted CSV file provided by the system.

## 4. Communication
- **Notifications**: Receive alerts when students submit assignments or reply to Help Desk tickets.
- **Help Desk**: Raise issues with administration regarding software bugs, timetable conflicts, or infrastructure issues.
